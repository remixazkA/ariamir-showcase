# Security Policy

## Scope

This repository is a public showcase and intentionally contains no production source tree, credentials, private configuration or user data.

## Reporting sensitive information

Do **not** open a public issue containing API keys or tokens, passwords or credentials, private user data, private filesystem paths or infrastructure details, undisclosed vulnerabilities in private Ariamir builds or unannounced partner information.

If you discover sensitive material in this repository, contact the project maintainer privately through the contact options associated with the GitHub account rather than reposting the material publicly.

## Showcase security objective

The public repository should remain safe to clone and inspect. It should not require production secrets, execute untrusted setup scripts, or contain enough proprietary implementation detail to recreate private Ariamir subsystems.
