# Benchmarks

Ariamir benchmark pages separate **methodology** from **results** so that public claims can be updated without changing what a metric means.

Current benchmark tracks:

- [`local-llm.md`](local-llm.md) — local model inference and workload behaviour.
- [`document-engine.md`](document-engine.md) — document quality, fidelity and latency.
- [`hardware.md`](hardware.md) — component and workstation compatibility/performance.

## Publication standard

A benchmark result should not be published merely because a number is available. Public results should state the tested configuration, workload, run conditions, metric definition and any material caveats.

No placeholder number in this repository should be interpreted as a measured result. Until a sanitized run is available, the benchmark page should say that results are pending publication.
