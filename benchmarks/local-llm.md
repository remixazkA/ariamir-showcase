# Local LLM Benchmark

## Purpose

Measure practical local-model behaviour on Ariamir's reference hardware without exposing private routing logic or prompts.

## Metrics

Candidate public metrics include:

- model and quantization identifier;
- context size used in the run;
- prompt/input token count;
- generated token count;
- time to first token/output;
- sustained generation throughput;
- peak VRAM use;
- peak system RAM use;
- completion success/failure;
- task-quality score for a public or synthetic evaluation set.

## Reference configuration

- Intel Core i7-12700KF
- NVIDIA GeForce RTX 4080 16 GB
- 32 GB system RAM
- Windows x64
