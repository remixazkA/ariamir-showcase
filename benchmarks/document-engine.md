# Document Engine Benchmark

## Purpose

Measure whether Ariamir can turn source material and structured AI work into useful document outputs while preserving content quality.

## Candidate test dimensions

- text extraction fidelity;
- heading and hierarchy preservation;
- table handling;
- citation/source retention where applicable;
- multi-page consistency;
- layout defects;
- artifact generation success rate;
- processing latency;
- human review score on a fixed synthetic/public test set.

## Test data policy

Public benchmark documents must be synthetic, public-domain, openly licensed or otherwise redistributable. Private user documents are not used as showcase benchmark material.
