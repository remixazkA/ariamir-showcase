# Media

This directory is reserved for sanitized public media.

- `screenshots/` — UI and workflow screenshots.
- `demos/` — short demo clips or links/manifests for externally hosted media.
- `diagrams/` — public architecture and workflow diagrams.

All media must pass the checklist in [`../docs/public-disclosure-policy.md`](../docs/public-disclosure-policy.md) before publication.

Do not add raw desktop recordings, debug captures or screenshots containing private paths, prompts, credentials, personal data or unapproved partner material.
