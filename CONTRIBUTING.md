# Contributing

Ariamir itself is not being published as an open-source codebase through this repository. Public contributions are therefore focused on **compatibility evidence, reproducibility feedback and documentation corrections**.

Useful contributions include:

- reporting whether a hardware configuration works with a publicly documented Ariamir workload;
- identifying an error in a benchmark methodology page;
- supplying additional reproducibility details;
- reporting broken links or unclear public documentation.

Please do not submit reverse-engineered proprietary code, leaked prompts, private configuration, credentials, third-party confidential material or user data.

For hardware reports, use the Hardware Compatibility Report issue template and remove sensitive identifiers before posting logs or screenshots.
